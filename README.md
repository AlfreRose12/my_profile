# alfrerose.dev — Portafolio

Portafolio personal de Alfredo Rosas Espinosa (`@alfrerose.dev`), Ingeniero en Desarrollo y Gestión de Software. SPA construida con React y Vite que presenta servicios, tecnologías, entorno de trabajo, proyectos destacados y formas de contacto.

## Secciones del sitio

- **Hero** — Presentación y llamadas a la acción (Ver Servicios / Cotizar Proyecto).
- **Filosofía** — Enfoque de desarrollo asistido por IA.
- **Servicios** — Sitios web, apps móviles, formularios, hospedaje, soluciones con IA y soporte.
- **Tech Stack** — Tecnologías y frameworks con los que trabajo.
- **Entorno de trabajo** — Infraestructura local y en la nube (dual-boot / VPS).
- **Proyectos** — Proyectos destacados con enlace a GitHub.
- **Contacto** — Instagram y correo electrónico.

## Stack tecnológico

- React 19
- Vite 8
- pnpm
- oxlint (lint)
- Iconos de tecnología vía [skillicons.dev](https://skillicons.dev)

## Configuración local

```bash
pnpm install   # instalar dependencias
pnpm dev       # servidor de desarrollo
pnpm lint      # ejecutar oxlint
pnpm build     # build de producción en dist/
pnpm preview   # previsualizar el build en local
```
